# Security Policy

## Supported Versions

I will only do security updates for the newest version of the plugin.

| Version | Supported          | Vulnerability | Notes | Game Version |
| ------- | ------------------ |---------------|-------|--------------|
| 1.0.0   | :x:                | no            |       | 1.363        |
| 2.0.0   | :x:                | no            |       | 1.363        |
| 2.0.1   | :x:                | no            |       | 1.363        |
| 2.1.0   | :x:                | no            |       | 1.363        |
| 2.2.0   | :white_check_mark: | no            |       | 1.363, 1.37  |

## Reporting a Vulnerability

If you find a vulnerability, please create a [Private vulnerability report](https://github.com/Bacnof/Banana-Shooter-Suicide-Plugin/security/advisories).
